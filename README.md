# AI Career Counselling System

## 📌 Overview
The AI Career Counselling System is a Flask-based web application that provides personalized career recommendations based on users' skills, interests, education, and career goals. It also includes an AI chatbot to assist users with career-related queries.

## ✨ Features
- User Registration and Login
- AI Career Recommendation
- Interactive Career Chatbot
- Career Information Dashboard
- Career Statistics
- Responsive User Interface

## 🛠️ Technologies Used
- Python
- Flask
- HTML5
- CSS3
- JavaScript
- JSON
- Bootstrap

## 📂 Project Structure
```
├── app.py

├── chatbot.py
├── data/

├── static/
├── requirements.txt
└── README.md
```

## 🚀 Installation

```bash
git clone https://github.com/mahnoor421/ai-career-counselling-system.git
cd ai-career-counselling-system
pip install -r requirements.txt
python app.py
```
