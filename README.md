# 🤖 AI Career Counselling System

An AI-powered career counselling web application that helps users explore suitable career paths based on their interests, skills, education, and career goals. The platform provides personalized career recommendations and features an interactive AI chatbot that answers career-related questions in real time.

---

## 🌟 Features

- 🔐 User Registration & Login
- 🤖 AI Career Chat Assistant
- 🎯 Personalized Career Recommendations
- 📚 Career Information and Guidance
- 💬 Interactive AI Chat Interface
- 📊 Career Dashboard
- 💾 Chat History Export
- 📱 Responsive User Interface

## 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/mahnoor421/ai-career-counselling-system.git
```

### Navigate to the project directory

```bash
cd ai-career-counselling-system
```

### Install the required packages

```bash
pip install -r requirements.txt
```

### Run the application

```bash
python app.py
```

Open your browser and visit:

```
http://127.0.0.1:5000
```

## 💡 How It Works

1. Register a new account or log in.
2. Explore available career options.
3. Receive personalized career recommendations.
4. Interact with the AI Career Chat Assistant.
5. Save or export your chat history.
